# Portal Sayembara Logo HUT ke-14 Mamuju Tengah

Portal web untuk pengumpulan karya lomba desain logo Kabupaten Mamuju Tengah.

## Tech Stack

**Backend:**
- Express.js + TypeScript
- Prisma ORM (PostgreSQL)
- Supabase Storage
- Supabase Auth

**Frontend:**
- Next.js 14+ (App Router)
- Tailwind CSS + shadcn/ui
- TypeScript

## Deployment

- Backend: Render
- Frontend: Vercel
- Database & Storage: Supabase
